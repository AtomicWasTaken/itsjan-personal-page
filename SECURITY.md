# Security policy

## Supported version

Security fixes are applied to the latest version on the `main` branch. Older
commits and forks are not maintained by this project.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for this repository when it is
available. Otherwise, send a concise report to [hi@itsjan.dev](mailto:hi@itsjan.dev)
with:

- the affected route or component;
- steps to reproduce the issue;
- the expected security impact; and
- any suggested mitigation.

You should receive an acknowledgement within seven days. Please allow time for
a fix before publishing details.
