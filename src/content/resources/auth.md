# Authentication

itsjan.dev is a public personal portfolio. Reading the website, Markdown profiles, LLM context files and public profile skill does not require an account, API key, OAuth flow or agent registration.

## Public resources

The following resources are available without credentials:

- https://itsjan.dev/en.md
- https://itsjan.dev/de.md
- https://itsjan.dev/llms.txt
- https://itsjan.dev/llms-full.txt
- https://itsjan.dev/skills/itsjan-profile/SKILL.md
- https://itsjan.dev/.well-known/agent-skills/index.json

## Agent registration

There is no registration endpoint because the site does not expose authenticated agent actions or a protected API. Agents can fetch the public resources directly.

## Contact

Questions about the published information can be sent to [hi@itsjan.dev](mailto:hi@itsjan.dev). Do not send credentials or secrets because the site does not need them.
