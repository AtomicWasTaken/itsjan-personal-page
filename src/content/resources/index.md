# Jan-Marlon Leibl

I'm Jan-Marlon, a software developer from Bremen, Germany, and the founder of Finny. I started programming at 11 with C#. Today I mainly work with PHP, TypeScript, React and Next.js.

## What I am working on

My current project is [Finny](https://fnny.app), an app that keeps receipts, purchase details and warranty dates in one place. I am building it because I wanted a simpler way to find purchase information and get a reminder before a warranty expires.

When I am not working on an application, I usually have something to do in my homelab. I run a Proxmox node, maintain my home network, upgrade hardware and troubleshoot whatever stopped working.

## Experience

### Finny, since 2026

I design and develop Finny in Bremen. The application uses TypeScript, React and Next.js.

### team neusta, 2023 to 2026

I completed a three-year software development apprenticeship at team neusta in Bremen. I worked on client projects with PHP, TypeScript and TYPO3. My broader stack there included Symfony and Git. During the same period, I attended vocational school at Schulzentrum SII Utbremen.

### Ventry, 2023 to 2024

I built [Ventry](https://ventry.host) because I wanted to share files through links without leaving the files online forever. A Ventry link expires and removes the shared file automatically. I built the project with TypeScript and Next.js.

### Homelab

I operate a Proxmox server and a small home network. This is where I work with Linux, Windows, virtualization, hardware upgrades and practical infrastructure problems.
